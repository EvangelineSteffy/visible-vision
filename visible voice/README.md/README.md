# visible vision - Tamil

## About the Project

visible vision is a Tamil-first digital assistant that helps users understand
government schemes in simple Tamil.

## Features

- Tamil-only interface
- Tamil text questions
- Tamil voice input
- Tamil voice responses
- Eligibility guidance
- Document guidance
- Application guidance
- Official government website link
- Privacy-focused design

## Technologies Used

- Python
- HTML
- CSS
- JavaScript
- Speech Recognition
- Speech Synthesis
- Gemini AI (optional)
